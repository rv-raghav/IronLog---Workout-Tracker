# Future Improvements

## Short-term

- **📈 Progress Graphs** — Chart exercise volume and weight over time using a charting library (e.g., Recharts)
- **🏆 PR Highlighting** — Automatically detect and highlight personal records on sets
- **🌓 Light/Dark Toggle** — Support both light and dark themes with a toggle in the navbar
- **📥 Import Workouts** — Allow importing previously exported JSON files back into the app

## Medium-term

- **📊 Weekly Volume Summary** — Dedicated analytics page showing weekly/monthly volume, frequency, and trends
- **🔍 Exercise Search** — Searchable exercise database with autocomplete
- **📱 PWA Support** — Service worker + manifest for installable app on mobile devices
- **🕒 Rest Timer** — Built-in countdown timer between sets
- **🏷️ Workout Tagging** — Tag workouts by day type (Push/Pull/Legs) automatically

## Long-term

- **☁️ Backend Sync** — RESTful API backend (Node.js/Express or Go) with database (PostgreSQL)
- **🔐 Authentication** — User accounts with email/password or OAuth (Google, GitHub)
- **👥 Social Features** — Share workouts, compare with friends
- **🤖 AI Recommendations** — Suggest exercises, detect plateaus, recommend deloads
- **📊 Body Composition** — Track bodyweight, measurements, and body fat percentage
- **🏋️ Exercise Library** — Animated exercise demos and form tips
